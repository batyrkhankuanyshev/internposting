Getting notified

The scanner runs on GitHub Actions every 6 hours. When it finds a new opening at a company in your tracker, or a university internship scheme posts a newer job list, it:

  • Opens a GitHub issue listing the new roles and mentions you, so GitHub emails you (and pushes to the GitHub mobile app). Make sure email notifications are on under GitHub → Settings → Notifications.
  • Updates the RSS feed at feed.xml. Add it to any reader (Feedly, Inoreader, Slack's RSS app).
  • Sends a phone push via ntfy (optional). Install the free ntfy app, subscribe to a hard-to-guess topic name, and save that name as the repository secret NTFY_TOPIC.

"NEW" badges on this page mark openings that appeared since your last visit in this browser, and "UPDATED" marks a scheme job list that changed since then. Applied and hidden marks are also kept in this browser only.

Some university pages, such as CityU's, sit behind a bot check that can stop the automatic check. When that happens, the scheme card says so and shows the date last confirmed.

Sources: company careers sites (Workday, Greenhouse, Oracle, Eightfold, SuccessFactors, Oleeo, PageUp, Ashby…), university internship scheme pages, and LinkedIn's public job search for Hong Kong. RSS
